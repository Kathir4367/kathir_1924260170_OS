# CSA04 Operating Systems Lab Experiments

Programs are organized by experiment number. Each experiment directory contains `program.c` and illustrative `sample_output.txt`. Sample outputs are not captured screenshots from a terminal session.

## Experiments uploaded so far

- 1: Process creation / PID and PPID (`fork`, `getpid`, `getppid`)
- 2: File copy
- 3: FCFS CPU scheduling
- 4: SJF burst-time ordering
- 5: Priority scheduling
- 6: Preemptive priority scheduling (processes assumed available at time zero)
- 7: Non-preemptive SJF with arrival times
- 8: Round Robin scheduling
- 9: Shared memory IPC
- 10: Message queue IPC

Compile C programs with GCC; pthread-based experiments require `-pthread`.
